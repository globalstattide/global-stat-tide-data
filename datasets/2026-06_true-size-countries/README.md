# The True Size of Countries: 193 Countries Ranked by Area

**Video:** [Why Your World Map is Lying to You (True Size Ranking)](https://www.youtube.com/watch?v=hakElUGVBIU), published 19 June 2026
**Rows:** 193 countries and territories, ranked by total area

## Files
| File | Contents |
|---|---|
| `data.csv` | The full ranking. Browse it right here on GitHub |
| `GST_True_Size_of_Countries.xlsx` | The same data plus a Sources sheet |

## What's inside
| Column | Meaning |
|---|---|
| Total Area (km²) | Land plus inland water |
| Share of World Land Area % | Our calculation: area ÷ 148,940,000 km² |
| Population, Population Density | How crowded each country really is: Monaco has over 19,000 people per km², Russia about 8 |

## Sources
- **Area:** total area in km² from UN Statistics Division and national figures.
- **Population:** 2025 estimates as listed by World Population Review, based on UN data.
- **Shares and density:** calculated by Global Stat Tide.

## Corrections
- **Guinea (rank 78):** the card shows 17,098,242 km², which is Russia's figure. The correct value is **245,857 km²**.
- **Cambodia:** the card labels the region "Latin America". Cambodia is in **Asia**.
- **World share:** some rounded shares on the cards were inconsistent. For example, Greenland showed 0.28% when the correct figure is about 1.45%. This file replaces them with one calculated column.
- **Greenland** is a territory of Denmark, included for comparison.
