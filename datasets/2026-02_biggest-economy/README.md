# The Biggest Economy on Earth — 184 Countries Ranked by GDP

**Video:** [The Biggest Economy on Earth Isn't Who You Think](https://www.youtube.com/watch?v=LCWdVo3-ajE) · published 22 February 2026
**Rows:** 184 countries · **Unit:** US dollars, current prices

## Files
| File | Contents |
|---|---|
| `data.csv` | The full ranking: open it right here on GitHub to browse and search |
| `GST_Biggest_Economy_GDP.xlsx` | Same data as an Excel workbook, plus a Sources sheet |

## Columns
| Column | Meaning |
|---|---|
| Rank | Position in the video (1 = largest economy) |
| GDP (as shown in video) | The rounded figure shown on the video card |
| GDP 2025 (USD billions) | Nominal GDP, 2025 estimate |
| GDP per Capita 2025 (USD) | GDP divided by population, same release |
| GDP 1960 … 2024 (USD billions, World Bank) | Historical GDP, so you can see how each economy grew |
| Note | Corrections and non-IMF sources |

## Sources
- **GDP 2025 and GDP per capita:** IMF *World Economic Outlook*, October 2025. Economies the IMF does not cover (for example Monaco, Liechtenstein, Cuba, North Korea) use the latest World Bank / UN figure, noted row by row.
- **GDP 1960–2024:** World Bank, *World Development Indicators*, indicator NY.GDP.MKTP.CD, licensed CC BY 4.0. Historical values cover 143 of the 184 countries; blank cells mean no figure in the extract used.

## Corrections
- **Germany (rank 3):** the video card reads $5.1T. The source value is **$5.01 trillion**. The ranking is unchanged.

## Method
Countries are ranked by nominal GDP in current US dollars. Nominal GDP measures the size of an economy at market exchange rates. It is not adjusted for cost of living (PPP) and is not a measure of how rich the average citizen is.
