# Why Some Countries Are Still Offline: Internet Users in 145 Countries

**Video:** [Why Some Countries Are Still Offline in 2026](https://www.youtube.com/watch?v=gIGCnAjCDzI), published 1 March 2026
**Rows:** 145 countries, ranked by the share of the population using the internet

## Files
| File | Contents |
|---|---|
| `data.csv` | The full ranking. Browse it right here on GitHub |
| `GST_Internet_Users_by_Country.xlsx` | The same data plus a Sources sheet |

## What's inside
| Column | Meaning |
|---|---|
| Internet Users % | Share of the population using the internet, rounded as shown in the video and as an exact figure |
| People Online / People Offline | Our calculation: population × share. This shows how many people that percentage really means |
| GDP per Capita | Compare a country's wealth with how connected it is |
| ITU / Our World in Data %, Year Actually Measured | A second source, and the year each country was last surveyed. Some figures are years old |

**Biggest offline populations:** India about 649 million, China about 318 million, Pakistan about 182 million, Nigeria about 141 million, Ethiopia about 114 million.

## Sources
- **Internet users %:** World Population Review, *Internet Users by Country 2026*, based on ITU data.
- **Second source and survey year:** Our World in Data, *Share of the population using the Internet*, from ITU via the World Bank.
- **Population:** 2025 estimates as listed by World Population Review, based on UN data.
- **GDP per capita:** IMF *World Economic Outlook*, October 2025.

## Corrections
- **Cambodia:** the card shows a population of 53,712,501, which is Colombia's figure. The correct value is **17,962,981**.
- **North Korea:** there is no official measurement. Public internet access is almost entirely banned, so it is shown as 0%.
