# Biggest Military Budget vs Biggest Army — 145 Countries + NATO

**Video:** [Biggest Military Budget vs Biggest Army: Who Really Wins?](https://www.youtube.com/watch?v=FsxlNynk-Ws), published 26 February 2026
**Rows:** 145 countries plus the NATO alliance total, ranked by military spending

## Files
| File | Contents |
|---|---|
| `data.csv` | The full ranking. Browse it right here on GitHub |
| `GST_Military_Budget_vs_Army.xlsx` | Same data, plus the full list of 176 countries' active forces and a Sources sheet |

## Columns
| Column | Meaning |
|---|---|
| Rank | Position in the video (1 = biggest budget) |
| Military Spending | Annual military expenditure in US dollars, as shown on the card and in millions |
| Active Military | Active-duty personnel, as shown on the card and corrected where needed |
| Spending per Active Soldier | Our calculation: budget ÷ active personnel. This shows how much money stands behind each soldier |
| Note | Corrections and special cases |

## Sources
- **Military spending:** SIPRI Military Expenditure Database, 2024 data, as listed by World Population Review in early 2026. SIPRI has since released 2025 figures, so newer numbers will differ.
- **Active personnel:** IISS, *The Military Balance 2025*, as listed by World Population Review.
- **NATO row:** the alliance total shown in the video. NATO is an alliance, not a country.

## Corrections
- **Cambodia (rank 89):** the card shows 269,000 active personnel, which is Colombia's figure. The correct value is **124,300**.
- **Greece (rank 34):** the card shows 20,650, which is Georgia's figure. The correct value is **132,000**.
- **Mauritius** has no standing army; its security forces are part of the police.
