# Where Is the World's Wealthiest Country? GDP per Capita for 209 Countries

**Video:** [Where Is the World's Wealthiest Country? GDP per Capita 2026](https://www.youtube.com/watch?v=2pTt8hRFDpw), published 25 June 2026
**Rows:** 209 countries and territories, ranked by GDP per capita. The video showed them A–Z; this dataset adds the ranking.

## Files
| File | Contents |
|---|---|
| `data.csv` | The full ranking. Browse it right here on GitHub |
| `GST_GDP_per_Capita.xlsx` | The same data plus a Sources sheet |

## Highlights
- **Top 3:** Monaco about $256,600, Liechtenstein about $231,700, Luxembourg about $146,800 per person.
- **Bottom:** South Sudan about $313 per person. The gap with Monaco is more than 800 to 1.

## Sources
- **GDP and GDP per capita:** IMF *World Economic Outlook*, October 2025 (2025 estimates). Economies the IMF does not cover use the latest World Bank or UN figure, noted row by row.
- **Population:** 2025 estimates as listed by World Population Review, based on UN data.
